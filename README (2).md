# Data Professionals Survey Breakdown | Power BI Dashboard

An end-to-end analytics project that transforms a raw, messy survey dataset into a clean, interactive Power BI dashboard exploring the roles, pay, demographics, and job satisfaction of data professionals.

![Status](https://img.shields.io/badge/status-complete-brightgreen) ![Tool](https://img.shields.io/badge/tool-Power%20BI-yellow) ![Data%20Cleaning](https://img.shields.io/badge/data%20cleaning-Excel-green)

## 📌 Project Overview

This project takes survey responses from data professionals — covering job titles, salaries, age, country, gender, and career satisfaction — and turns them into a single-page interactive dashboard. The raw data arrived in an inconsistent, unstructured state typical of real-world survey exports, so the bulk of the effort went into cleaning and preparing it before any visualization work began.

**Workflow:** Raw Excel data → Data Cleaning & Preparation (Excel) → Data Modeling & Visualization (Power BI) → Interactive Dashboard

## 🧹 Data Cleaning & Preparation

Before the data was analysis-ready, the following cleaning steps were performed in Excel:

- Standardized inconsistent text entries and categorical values
- Handled missing and blank responses
- Corrected formatting issues across columns (e.g., age, salary, country fields)
- Restructured the dataset into a clean, analysis-ready table

## 📊 Dashboard Features

The dashboard, **"Data Professionals Survey Breakdown,"** includes:

| Visual | Insight |
|---|---|
| KPI Card | Total number of survey takers |
| KPI Card | Average age of survey takers |
| Gauge | Happiness in current role (1–10 scale) |
| Gauge | Happiness in learning new things |
| Bar Chart | Roles breakdown of data professionals |
| Bar Chart | Average salary by role |
| Bar Chart | Survey takers by country |
| Clustered Bar Chart | Most important reason for changing jobs |
| Donut Chart | Gender comparison of survey takers |
